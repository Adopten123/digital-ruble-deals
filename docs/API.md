# Проектный контракт API

Черновик, маршруты ещё не реализованы.

## Правила

amount_kopecks — положительное целое; валюта RUB. Роль определяется серверной сессией. Денежные команды используют Idempotency-Key. Согласие относится к версии условий.

Одинаковый ключ и тело возвращают прежний результат; другой запрос с тем же ключом — конфликт. Проверять права участника, не доверять user_id из тела.

## Маршруты

| Метод и путь | Действие | Доступ |
|---|---|---|
| POST /api/deals | Создать сделку | Заказчик |
| GET /api/deals/{id} | Условия и состояние | Участники |
| POST /api/deals/{id}/agree | Подтвердить версию | Соответствующая сторона |
| POST /api/deals/{id}/reserve | Резерв | Заказчик |
| POST /api/deals/{id}/disputes | Открыть спор | Участник |
| POST /api/deals/{id}/cancellation-consents | Согласие на отмену | Сторона |
| GET /api/deals/{id}/audit | История | Участники / оператор по роли |
| POST /internal/edo/events | Событие ЭДО | Проверяемый адаптер |
| POST /demo/edo/events | Сгенерировать демо-событие | Демо-оператор |

Публичного маршрута выплаты в обход условий нет.

## Событие

```json
{
  "schema_version": 1,
  "event_id": "edo-demo-001",
  "source": "edo-emulator",
  "event_type": "document.accepted_by_both",
  "deal_id": "deal-demo-001",
  "deal_version": 1,
  "document_id": "document-demo-001",
  "document_version": 1,
  "document_sha256": "<sha256 содержимого>",
  "customer_party_id": "company-customer-demo",
  "supplier_party_id": "company-supplier-demo",
  "amount_kopecks": 30000000,
  "currency": "RUB",
  "signed_by_customer": true,
  "signed_by_supplier": true,
  "occurred_at": "2026-10-09T09:00:00Z"
}
```

Наш нормализованный формат, не формат ЦБ или конкретного оператора. Подпись источника передаётся отдельно. Булевы поля принимаются только от проверенного источника с согласованной семантикой.

## Отказы

Недостаток средств; отсутствие согласований; неверный источник; чужая сделка; неверные стороны, сумма, валюта, документ или версия; одиночная подпись; открытый спор; завершённая/отменённая сделка; конфликт ключа.

Аннулирование и противоречивое событие требуют предусмотренной проверки. Ошибки имеют понятные коды без секретов и чужих данных.
