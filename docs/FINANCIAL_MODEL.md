# Предварительная экономическая модель

Статус: структура расчёта. Цена и себестоимость продукта не установлены.

## Единица анализа

Завершённая сделка между компаниями / ИП с одним документом и одним расчётом. Отдельно учитывать отмены, споры, проверки и возвраты.

[Сравнение альтернатив для SCN-001](ALTERNATIVES.md) содержит тарифные примеры и границы их применимости. Перевод внутри пакета РКО может не требовать добавочной комиссии; 15 ₽ сами по себе не доказывают экономию. Пример 9 000 ₽ по двум строкам специального предложения аккредитива не является общей ценой рынка или котировкой для типографии. Цену для клиента и себестоимость сервиса оценивать отдельно, учитывая также отвлечение оборотных средств.

Тариф B2B-перевода: 0 ₽ до конца 2026 года; 15 ₽ с 1 января 2027 года. Это одна составляющая затрат. Для самозанятого без ИП нельзя автоматически применять B2B-классификацию.

[Официальный тариф](https://www.cbr.ru/rbr/dir_decisions/rsd_2026-08-28_45_01/)

## Полная стоимость

C = C_расчёта + C_ЭДО + C_проверок + C_инфраструктуры + C_поддержки + C_споров + C_интеграций

- Расчёт: все платёжные действия и возвраты.
- ЭДО: события, проверка, хранение и оператор.
- Проверки: полномочия, источники и исключения.
- Инфраструктура: эксплуатация и наблюдаемость.
- Поддержка: обращения и восстановление.
- Споры: вероятность спора × средняя стоимость урегулирования.
- Интеграции: адаптеры и сопровождение, распределённые на объём.

Привлечение, внедрение и постоянную разработку также включить в модель продукта.

## Гипотезы дохода

Лицензия и сопровождение для банка; подписка/API для партнёра; отдельная услуга сопровождения сделки после проверки её модели. Произвольная плата за базовый цифровой перевод не предполагается. Монетизация витрины ПКСК не считается установленной.

## Формулы

- Вклад сделки = доход сделки − переменные затраты.
- Месячный результат = вклад сделок + подписки − постоянные расходы.
- Безубыточный объём = непокрытые постоянные расходы / положительный вклад сделки.
- Окупаемость считать по денежному потоку; при неположительном потоке она не достигнута.

| Средний чек и частота | Интервью и пилот |

| Доля споров и отмен | Данные процесса |

| Стоимость исключения | Время × стоимость труда |
| Интеграция и сопровождение | Оценка команды и банка |

## Ценность для банка

Гипотезы: новый расчётный сценарий для МСБ, вовлечённость в приложение и меньше ручной обработки типовых условий. Доход от размещения резервов цифрового рубля не включать.
