## Что определено

- «ПоАкту», условный B2B-расчёт по двусторонней подписи конкретного документа. SCN-001 — рабочий учебный пример печатных работ.
- Go + PostgreSQL + TypeScript; модули / ручная сборка по go-todoapp-1; React / Vite как конкретизация frontend; единая денежная транзакция.
- Регистрация новой учебной организации владельца, customer / supplier от конкретной сделки, отдельный демооператор.
- PDF, подписи, резерв, одна выплата, спор, согласованная отмена, несколько сделок, уведомления, поиск, CSV / JSON входят в первый выпуск.
- Docker Compose одной командой. Жюри получает репозиторий и запускает локально; публичное размещение не требуется для выбранного показа.
- Средства, события и подписи учебные, маркировка контура обязательна. Banking-system полностью исключён.
- Из [go-todoapp-1](https://github.com/Adopten123/go-todoapp-1) берётся архитектурный подход, не готовое денежное / авторизационное ядро.

## Работа на двух ПК

Оба разработчика начинают с одного согласованного коммита и API. На каждом ПК отдельный clone, volumes и учебные данные. Незакоммиченные файлы автоматически не синхронизируются.

| Поток | Область | Ответственность |
|---|---|---|
| Backend | cmd, internal, migrations, integration tests | Auth / org scope, реестр, события, спор / отмена, поиск / экспорт |
| Frontend | web, UI tests, экранный сценарий | Кабинеты, PDF, состояния, панель оператора, связь с API |
| Совместно | API, Compose, версии / lock-файлы, критерии приёмки | Общий контракт и воспроизводимая сборка |

Сначала одним согласованным изменением создать каркас и зафиксировать API. Далее — отдельные ветки, например `feature/backend-core` и `feature/frontend-demo`. На время изменения у каждого общего файла один владелец. Номера миграций уникальны; после интеграции проверяется чистая БД. Контракт меняется вместе с обеими сторонами. Небольшие коммиты и pull request, без force push общего прогресса.
