## Ограничения и следующий этап

Регистрация, загрузка пользовательского PDF, реальные устройства / экранная клавиатура, другие браузеры, zoom и полная матрица [ручного руководства](../MANUAL_TESTING.md) в этом повторе не проверялись. Потеря ответов, конкурентные команды и перезапуск сервера остаются результатами автоматического набора исходного отчёта; повторно эти тесты здесь не запускались. Подписи, ЭДО, выплата, спор / отмена и A19 ещё отсутствуют.

Следующий небольшой этап — **тестовые подписи после резерва**: каждая организация подписывает только за себя, с точными версиями / хешем документа. Первая подпись не меняет деньги; вторая создаёт один устойчивый факт для доставки ЭДО и состояние READY_TO_SETTLE. Нужны проверки прав, подмены версий / хеша, повторов, параллельных подписей и восстановления после потери ответа. Согласия до резерва остаются отдельными фактами.

Затем — доставка / HMAC / inbox ЭДО и единственная атомарная выплата. Для неё необходим отдельный путь погашения собственного резерва: обычное списание по available не подходит, проверку доступного остатка остальных списаний ослаблять нельзя. Блокировки спором / отменой и гонки с выплатой должны быть готовы до приёмки полного расчётного сценария. Каждое расширение включает свои API / UI / PostgreSQL-тесты, после чего расширяются сквозной набор и ручной прогон.
