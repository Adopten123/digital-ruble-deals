## Как вести записи

1. Перед разговором выбрать роль респондента и вопросы. Рабочий ориентир команды — 10–15 интервью, а не обязательная квота организаторов. Сначала поговорить с заказчиками и исполнителями, затем уточнить сегмент.
2. На каждый разговор создавать отдельный Markdown-файл в `records/`: `YYYY-MM-DD-int-001.md` для интервью или `YYYY-MM-DD-team-001.md` для обсуждения. Использовать соответствующий шаблон и уникальный ID.
3. Сохранять исходный пересказ, примеры, противоречия и неудобные детали. Не заполнять пропуски догадками; писать «не уточнили». Цитаты выделять только при дословной записи, остальное помечать как пересказ.
4. После разговора добавить ссылку в реестр, а связанные наблюдения — в сводку с ID интервью и разделом записи.
5. Отделять рассказ респондента от нашей интерпретации. Повторение мнения в нескольких интервью не превращает его в подтверждённую статистику рынка.
6. Решения команды фиксировать с датой и основанием. Принятые изменения продукта переносить в [CONTEXT.md](../CONTEXT.md), задачи — в [BACKLOG.md](../BACKLOG.md). Предложение респондента само по себе не меняет продукт.

В Git сохраняем обезличенные исследовательские заметки: коды респондентов, роли, обобщённые диапазоны и описание процесса. Не добавляем ФИО, контакты, реквизиты, реальные договоры, платёжные документы и записи разговоров. Если исходные материалы нужны отдельно, в заметке достаточно указать ответственного без приватной ссылки или пути.

Интервью, презентация и заметки спикера — источники сведений и гипотез. Решения по разработке фиксируются отдельно в контексте проекта и правилах репозитория.

## Текущее состояние

19 октября 2026 года подготовлена структура исследования. Проведённых интервью и подтверждённых пользовательских выводов в этой папке пока нет. Первая запись отражает только обсуждение с пользователем.

По запросу пользователя добавлены два пробных диалога: барберная в Курске и самостоятельный продавец ESSENS в Москве. Они хранятся в `simulations/`, имеют ID `SIM`, не учитываются как интервью и не подтверждают гипотезы в FINDINGS.md.
