# Пробные интервью

Это смоделированные диалоги по описаниям пользователя. Разговоров с предпринимателями не было. Используем для проверки вопросов и тренировки интервьюера; не включаем в число проведённых интервью, доказательства спроса или расчёт рынка.

- [SIM-001: владелец барберной, Курск](2026-10-19-sim-001-barbershop.md).
- [SIM-002: самостоятельный продавец ESSENS, Москва](2026-10-19-sim-002-essens.md).

В каждом файле отдельно указаны вводные пользователя и придуманные детали. Реплики написаны от первого лица для живого звучания; это не реальные цитаты. Дата в названии — дата генерации, не интервью. Согласие, контакты, участие в пилоте и реальные договорённости не моделируются как полученные.

Ответы идут по 15 темам исправленного пользователем [сценария](../INTERVIEW_GUIDE.md). Вопросы адаптированы под закупку товаров: акт выполненных работ не подставляется туда, где речь о поставке.

Для настоящего интервью создать отдельную запись по [шаблону](../templates/INTERVIEW.md). Не переименовывать симуляцию в проведённое интервью и не переносить вымышленные ответы в результат исследования.
