# Frontend «ПоАкту»

React / TypeScript / Vite. Текущий этап: авторизация, организации, версии условий / PDF, согласование / доработка, резерв и панель учебных счетов оператора. Реализованы тестовые подписи после резерва, ожидание / результат однократной выплаты по ЭДО, спор / двусторонняя отмена и панель событий оператора. История сделки / оператора, фильтры и CSV / JSON показывают разрешённые сохранённые факты; документация API 0.6.0 описывает 35 операций.

- [Автоматические проверки](../docs/TESTING.md) и [ручная инструкция](../docs/MANUAL_TESTING.md)

Из корня репозитория: `npm --prefix web ci --ignore-scripts`, затем `npm --prefix web run dev`. Backend запускается отдельно; origin `http://localhost:5173`, proxy на `127.0.0.1:8081`. Swagger-assets готовятся автоматически перед dev/build. Не коммитить generated output или данные сессий.
