# Frontend «ПоАкту»

React / TypeScript / Vite. Текущий этап: авторизация, организации, версии условий / PDF, согласование / доработка, резерв и панель учебных счетов оператора. Реализованы тестовые подписи после резерва, ожидание / результат однократной выплаты по ЭДО, спор / двусторонняя отмена и панель событий оператора. История сделки / оператора, фильтры и CSV / JSON показывают разрешённые сохранённые факты; документация API 0.7.0 описывает 37 операций. В кабинете организации есть уведомления о сохранённых фактах: непрочитанный счётчик, фильтры / пагинация, отметка прочтения и переход к актуальной сделке. Polling работает каждые 15 секунд и при фокусе, старые запросы отменяются при смене аккаунта.

Из корня репозитория: `npm --prefix web ci --ignore-scripts`, затем `npm --prefix web run dev`. Backend запускается отдельно; origin `http://localhost:5173`, proxy на `127.0.0.1:8081`. Swagger-assets готовятся автоматически перед dev/build. Не коммитить generated output или данные сессий.

Текущий backend требует схему 009 и возвращает readiness stage=notifications. При обновлении сохранить БД / ключ / PDF, выполнить migrate, оба файла runtime-grants, bootstrap и restart; точный порядок — в RUNNING.md. Уведомления сохраняют отдельные времена факта и доставки, а прочитанность переживает reload / restart. POST отметки имеет пустое тело и не требует Idempotency-Key. A19 остаётся отдельным этапом.
